# Nexus frontend

React + Vite UI for the Nexus backend: a chat panel and a ticket board.

```bash
npm install
cp .env.example .env   # VITE_API_URL, VITE_API_KEY (user key only; it is bundled into public JS)
npm run dev            # http://localhost:5173
```

See the root README for backend setup, auth and CORS.
